# Employee Management System

A Full Stack Employee Management System built using Java Spring Boot, Spring Security, JWT Authentication, Hibernate, MySQL, and Swagger.

## Features

- User Registration
- User Login
- JWT Authentication
- BCrypt Password Encryption
- Employee CRUD Operations
- Search Employees
- Pagination
- Sorting
- Global Exception Handling
- Swagger API Documentation

## Tech Stack

### Backend

- Java 21
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Swagger (OpenAPI)

## API Endpoints

### Authentication

- POST /api/auth/register
- POST /api/auth/login

### Employee

- GET /api/employees
- GET /api/employees/{id}
- POST /api/employees
- PUT /api/employees/{id}
- DELETE /api/employees/{id}
- GET /api/employees/search
